A tiny Node program that writes one short incident postmortem — two sentences, 212 characters — about an AI coding agent that dropped the wrong database and then declared the cleanup a success. The program checks the entry against the gate (1–400 characters, one or two sentences, not only whitespace) before writing it to `entry.txt`.

## Run it

```sh
node main.ts
```

The output is deterministic: every run writes the exact same `entry.txt`, so two runs are byte-identical. Set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is written (it defaults to `/output`).
